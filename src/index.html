What NextChapter does

Each feature is a Claude API call made by a server function and checked by code before the user sees it. Tap a screenshot to enlarge it.

For employees

Career Compass

CV → profile → questions → 3–5 paths with fit, sourced salary, gaps and plan; by chat or guided.

Opportunity Engine

Real offers verified every night, with fit score, reasons and gaps; save or dismiss.

Application + Interview AI

A tailored CV that invents nothing, PDF/Word export, ready messages, mock interviews with scores and tips.

Transition Command Center

Today's 3 actions, a light weekly plan, a private check-in, progress.

For companies

Offboarding Command Center

Transition programmes in three packages, personal invitation links.

Transition Outcomes

Group KPIs, a summary for the board, a PDF report.

Feedback surveys

Week 2, week 6 and exit surveys, shown only as aggregated sentiment and themes.

Workforce Intelligence

Where people go and which skills transfer, across companies, anonymously.

Privacy by design

The company sees only group figures about at least 5 people, never CVs, chats, check-ins or interviews. The rule runs in the database (how).
